# URL 입력부터 화면 표시까지

브라우저 주소창에 URL을 입력하면 먼저 도메인 이름을 IP 주소로 바꾸는 DNS 조회가 일어난다. 브라우저 캐시, 운영체제 캐시, DNS 서버 순으로 찾아보며, 이미 방문한 적 있는 주소라면 캐시에서 바로 나온다.

IP를 알아내면 그 주소로 TCP 연결을 맺는다. HTTPS라면 TCP 연결 후 TLS handshake가 추가로 일어나 암호화 채널을 만든다. 연결이 서면 브라우저가 HTTP 요청을 보내고 서버가 응답을 돌려준다.

응답으로 받은 HTML을 브라우저가 위에서부터 읽으며 DOM 트리를 만든다. 중간에 CSS나 JavaScript 링크를 만나면 그 파일도 요청한다. CSS는 스타일 규칙 트리로 변환되고, DOM과 합쳐져 화면에 실제로 그려질 요소들의 배치를 계산한다. 각 요소의 위치와 크기를 정하는 단계를 거쳐 픽셀로 그려지면 화면에 나타난다.

JavaScript는 이 과정을 멈출 수 있다. 스크립트를 만나면 브라우저는 HTML 파싱을 중단하고 스크립트를 내려받아 실행한 뒤 재개한다. 스크립트가 DOM을 바꿀 수 있어서 순서를 보장해야 하기 때문이다. 그래서 스크립트 태그를 문서 끝에 두거나 나중에 실행하도록 표시해, 화면이 먼저 보이게 하는 방식이 널리 쓰인다.
