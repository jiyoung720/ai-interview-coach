# Tool Calling

## 무엇인가
사용자가 정의한 함수를 쓰는 tool calling에서, LLM은 답을 바로 쓰는 대신 어떤 함수를 어떤 인자로 호출할지 구조화된 요청을 내놓는다. 모델은 함수를 직접 실행하지 않는다. 애플리케이션(또는 SDK)이 그 요청을 실행하고 결과를 다시 모델에게 돌려준다. 모델은 함수 이름, 설명, 인자 스키마를 보고 어떤 도구를 쓸지 판단하므로, 도구 설명을 명확하게 쓰는 것이 중요하다. 일부 제공자는 검색 같은 내장 도구를 제공하기도 하는데, 이 경우 실행은 제공자 쪽에서 이루어진다.

## 실행 루프
모델이 도구 호출을 요청하면 애플리케이션이 실행하고 결과를 대화에 추가한 뒤 모델을 다시 부른다. 모델이 더 이상 도구를 부르지 않고 최종 답을 낼 때까지 이 과정을 반복한다. ReAct는 추론과 행동(도구 호출)을 번갈아 하며 관찰 결과를 다음 추론에 반영하는 방식이다.

## 실패 처리
모델은 존재하지 않는 도구를 부르거나 스키마에 맞지 않는 인자를 넣을 수 있으므로, 실행 전에 이름과 인자를 검증해야 한다. 도구가 실행할 수 있는 범위는 모델이 넘긴 인자가 아니라 애플리케이션이 허용한 권한으로 제한해야 한다. 같은 도구를 끝없이 반복 호출하지 않도록 호출 횟수 상한을 두고, 상한에 걸리면 중단하고 사유를 알리거나, 제한된 응답을 내거나, 사용자 확인을 받는 등 안전한 방식으로 처리한다. 호출 횟수 대신 실행 시간 예산을 두거나, 같은 호출이 진전 없이 반복되는지 감지하는 방법도 있다. 같은 도구를 여러 번 부르는 것 자체는 다음 페이지를 가져오는 경우처럼 정상일 수 있다.
